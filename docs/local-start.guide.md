Локальный запуск проекта

1. Установите зависимости Откройте терминал в папке проекта и выполните: pnpm
   install Если pnpm не установлен: npm install -g pnpm
2. Создайте .env В корне проекта создайте файл .env. Скопируйте в него:
   VITE_GREEN_API_URL=https://4100.api.green-api.com
3. Запустите приложение pnpm dev В терминале появится адрес примерно такого
   вида: http://localhost:5173 Откройте его в браузере.
4. Авторизуйтесь На стартовом экране введите данные своего инстанса GREEN-API:
   idInstance apiTokenInstance После этого откроется чат. Данные сохраняются
   только в localStorage браузера, поэтому после обновления страницы повторная
   авторизация не требуется.
5. Настройте получение сообщений GREEN-API
6. Создайте чат и отправьте сообщение Нажмите кнопку + слева. Введите номер
   собеседника. Создайте чат. Напишите сообщение справа. Нажмите «Отправить».
